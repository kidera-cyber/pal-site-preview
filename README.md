## Notes

本リポジトリはプレビュー環境です。
Google Analytics / GTM / Clarity等のアクセス解析タグは無効化しています。
本番サイトへの外部リンクは https://www.pal-style.co.jp/ を使用します。

4ページの HTML は WordPress から書き出したものを整理したもので、本文・見出し・図解・配色・レイアウトは本番のまま維持しています。
CSS / JS / 画像は本番テーマ（https://www.pal-style.co.jp/wp-content/themes/PCL/）を参照しているため、表示確認にはネットワーク接続が必要です。
